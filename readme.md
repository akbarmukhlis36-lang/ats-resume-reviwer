# 📄 ATS Resume Score & Optimizer App

An AI-powered Applicant Tracking System (ATS) resume reviewer built using **Streamlit** and **Google Gemini 1.5 Flash**.

## Features
- **PDF Resume Parsing**: Extracts structured text directly from PDF resumes.
- **Job Match Scoring**: Calculates a percentage match score based on job description alignment.
- **Keyword Gap Analysis**: Identifies critical matched and missing skills/terms.
- **Actionable Bullet Point Rewrites**: Recommends stronger, metric-driven achievements.
- **Formatting Advice**: Flags ATS readability and structure improvements.
- **PDF Report Export**: Download a full ATS analysis report directly as a PDF document.
